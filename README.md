# Sun Elastomer

Live Website: https://sun-elastomer.vercel.app

## Overview
A modern pharmaceutical and healthcare company website developed to showcase products, services, manufacturing capabilities, certifications, and customer inquiries.

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Database
- MongoDB

## Features
- Responsive Design
- Product Showcase
- Company Profile
- Contact & Inquiry Forms
- SEO Optimized Pages
- Modern UI/UX
- Fast Performance
